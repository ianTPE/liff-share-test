用 GitHub Pages + LIFF，從個人帳號發 LINE Flex 卡片

不用官方帳號、不花推播費。做一個網頁，在 LINE 裡打開、按一下、選好友，對方聊天室就會出現一張排版漂亮、可以點按鈕的卡片。

1原理：shareTargetPicker 是什麼

LINE App 本身沒辦法讓個人帳號發 Flex 卡片，一般人只能發文字、圖片、貼圖。但 LINE 的網頁小程式 LIFF 有一個功能 liff.shareTargetPicker()：呼叫它會跳出 LINE 內建的「選擇好友／群組」畫面，選好按送出，卡片就以你本人的名義送出。

官方帳號推播LIFF shareTargetPicker
誰發出官方帳號你自己的個人帳號
費用計入每月推播則數免費（算一般聊天）
能不能全自動可以不行，每次要本人選對象、按送出
卡片按鈕各種動作都能用只能「開網址」（uri）

需要準備：一個 LINE 帳號（登入 LINE Developers 用）、一個 GitHub 帳號、手機上的 LINE。

整個流程有一個先後問題：LIFF 要填網頁網址，網頁程式又要填 LIFF ID。所以順序是 建 channel → 寫網頁並上線 → 建 LIFF 拿到 ID → 把 ID 填回網頁。

2建立 LINE Login channel

  1. 打開 LINE Developers Console，用 LINE 帳號登入。
  2. 建立一個 Provider（名稱隨意，例如自己的名字或團隊名）。
  3. 在 Provider 底下按 Create a new channel，類型選 LINE Login。
  4. 填入 channel 名稱、說明、地區（Taiwan），App types 勾 Web app，同意條款後建立。
⚠️ 要選 LINE Login，不是 Messaging APIMessaging API channel（官方帳號的 Bot）不能掛 LIFF。

3寫網頁

整個網頁就一個 index.html。核心只有三件事：載入 LIFF SDK、liff.init()、按鈕按下時呼叫 liff.shareTargetPicker([訊息])。

下面是完整可用的範例，直接複製，存成 index.html。LIFF_ID 先留著，第 5 步拿到自己的 ID 再換掉。

<!doctype html>
<html lang="zh-Hant">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>分享 Flex 卡片</title>
<style>
  body { margin: 0; padding: 24px 16px; font-family: system-ui, sans-serif; text-align: center; }
  button { width: 100%; max-width: 360px; padding: 14px; font-size: 1rem; font-weight: 700;
           color: #fff; background: #06c755; border: 0; border-radius: 12px; }
  button:disabled { opacity: .5; }
  #status { margin-top: 14px; color: #666; }
</style>
</head>
<body>
  <h1>分享 Flex 卡片</h1>
  <button id="share" disabled>選擇好友並送出</button>
  <p id="status">載入中…</p>

<!-- 1. 載入 LIFF SDK -->
<script src="https://static.line-scdn.net/liff/edge/2/sdk.js"></script>
<script>
  // 2. 換成你自己的 LIFF ID
  const LIFF_ID = "2011736396-qcyiLRJ3";

  // 3. 要送出的 Flex 訊息（可以到 Flex Message Simulator 設計後貼進來）
  const message = {
    type: "flex",
    altText: "讀書會提醒：週四晚上 8 點",   // 聊天列表與通知顯示的文字
    contents: {
      type: "bubble",
      header: {
        type: "box", layout: "vertical", backgroundColor: "#06c755", paddingAll: "16px",
        contents: [
          { type: "text", text: "讀書會提醒", color: "#ffffff", size: "xl", weight: "bold" },
          { type: "text", text: "週四 20:00｜線上", color: "#e8fff0", size: "sm" }
        ]
      },
      body: {
        type: "box", layout: "vertical", spacing: "md",
        contents: [
          { type: "text", text: "這次讀第 3 章，記得先看完再來喔！", wrap: true },
          { type: "text", text: "這張卡片是用 LIFF shareTargetPicker 從個人帳號送出的。", wrap: true, size: "xs", color: "#888888" }
        ]
      },
      footer: {
        type: "box", layout: "vertical",
        contents: [
          // 用 LIFF 分享的卡片，按鈕只能用 uri（開網址）
          { type: "button", style: "primary", color: "#06c755",
            action: { type: "uri", label: "看教學文章", uri: "https://iantpe.github.io/liff-share-test/guide.html" } }
        ]
      }
    }
  };

  const $ = (id) => document.getElementById(id);

  async function main() {
    // 4. 初始化 LIFF
    await liff.init({ liffId: LIFF_ID });
    if (!liff.isLoggedIn()) { liff.login(); return; }           // 在一般瀏覽器打開時先登入
    if (!liff.isApiAvailable("shareTargetPicker")) {
      $("status").textContent = "無法分享：請在 LINE 裡打開，並在 LIFF 設定開啟 Share target picker。";
      return;
    }
    $("share").disabled = false;
    $("status").textContent = "";

    // 5. 按下按鈕 → 跳出 LINE 的選好友畫面 → 送出
    $("share").onclick = async () => {
      try {
        const res = await liff.shareTargetPicker([message]);   // 一次最多 5 則
        $("status").textContent = res ? "已送出 ✅" : "已取消";
      } catch (e) {
        $("status").textContent = "失敗：" + e.message;           // 多半是 Flex JSON 格式有誤
      }
    };
  }
  main().catch((e) => { $("status").textContent = "LIFF 初始化失敗：" + e.message; });
</script>
</body>
</html>

幾個重點：

  • altText 必填，聊天列表和手機通知只會顯示這段文字。
  • shareTargetPicker 的參數是陣列，一次最多 5 則訊息（例如一張卡片加一則文字）。
  • 回傳值有東西代表送出成功；使用者按取消時沒有回傳值。
  • 在電腦瀏覽器打開時，liff.login() 會先導到 LINE 登入頁；分享前可能還要用 email 和密碼登入一次。最順的還是在手機 LINE 裡打開。

4放上 GitHub Pages

  1. 在 GitHub 建一個新的 Public repository，例如 liff-card。
  2. 把 index.html 上傳（網頁上按 Add file → Upload files 就可以，不一定要用 git）。
  3. 進 repo 的 Settings → Pages，Source 選 Deploy from a branch，Branch 選 main、資料夾 / (root)，按 Save。
  4. 等一兩分鐘，頁面上方會出現網址：https://你的帳號.github.io/liff-card/。用瀏覽器打開確認看得到頁面。
💡 網址一定要 httpsLIFF 只接受 https 網址，GitHub Pages 預設就是 https，所以很適合。

5新增 LIFF 小程式

  1. 回到剛剛的 LINE Login channel，切到 LIFF 分頁，按 Add。
  2. 設定：
    • LIFF app name：隨意
    • Size：Full
    • Endpoint URL：第 4 步的 GitHub Pages 網址
    • Scopes：勾 profile
  3. 建立後回到 LIFF 列表，把 Share target picker 打開（On）。這步最常忘記，沒開就不能分享。
  4. 複製 LIFF ID（長得像 1234567890-AbCdEfGh），貼回 index.html 的 LIFF_ID，再上傳一次。

6在 LINE 裡打開、發送

  1. LIFF 網址是 https://liff.line.me/你的LIFF_ID。把這個網址傳給自己（或任何聊天室），在手機 LINE 裡點開。
  2. 頁面載入後按「選擇好友並送出」，會跳出 LINE 的選人畫面。
  3. 選好友或群組，按分享。對方聊天室就會出現卡片 🎉

想先看效果？在 LINE 裡打開這個範例：liff.line.me/2011736396-qcyiLRJ3/demo.html（這是本文的示範小程式，如果打不開，請看下面「限制與常見問題」的 channel 狀態說明）。

7設計自己的卡片

不要手寫 Flex JSON，用 LINE 官方的 Flex Message Simulator：

  1. 左上角 Showcase 有很多現成範本（餐廳、收據、行程…），挑一個接近的開始改。
  2. 左邊點元件改文字、顏色、圖片，右邊即時預覽。
  3. 按 View as JSON，複製整段 JSON。它是 bubble（單張）或 carousel（可左右滑的多張）。
  4. 貼到範例裡 contents: 後面，取代原本的卡片。

常用元件：

元件用途
box容器，layout 可以是 vertical（上下）、horizontal（左右）、baseline
text文字，長文字記得加 wrap: true 才會換行
image圖片，網址必須是 https；可以把圖片也放在同一個 GitHub repo
button按鈕，這裡只能用 uri 動作
separator分隔線
💡 小技巧圖片元件加 animated: true，放一張 APNG 動畫圖片，卡片就會動。Flex 的文字本身沒有動畫效果。

8限制與常見問題

按鈕能用哪些動作？

按鈕動作用 LIFF 分享能用嗎
開網址（uri）✅ 可以（網址最長 1,000 字）
回傳資料給機器人（postback）❌ 要官方帳號
替使用者送出一句話（message）❌ 要官方帳號
複製文字（clipboard）❌ 要官方帳號
選日期時間（datetimepicker）❌ 要官方帳號

「加入 Zoom」「填寫報名表」「看活動詳情」這類連到網址的按鈕都沒問題。

別人打不開我的 LIFF？

新建的 channel 是 Developing（開發中）狀態，只有管理員和測試人員能打開小程式。要給別人用，就在 channel 頁面上方把狀態從 Developing 改成 Published，或在 Roles 分頁把對方加成測試人員。
收卡片的人不受影響：卡片送出後，任何人都看得到。

顯示「無法分享」？

  • 確認 LIFF 設定裡 Share target picker 已打開。
  • 確認是用 https://liff.line.me/… 網址打開，而不是直接打開 GitHub Pages 網址。

按分享後出現錯誤？

多半是 Flex JSON 有錯（少逗號、欄位名稱打錯、數值不合法）。把 JSON 貼回 Flex Message Simulator，它會指出哪裡有問題。

改了網頁，LINE 裡還是舊版？

LINE 內建瀏覽器會快取頁面（GitHub Pages 約 10 分鐘）。在網址後面加 ?v=2、?v=3… 就會重新載入。

選人名單裡找不到某些好友？

  • 選人畫面不能選自己，也沒有 Keep 筆記。測試時可以發給家人，或開一個只有自己和一位朋友的小群組。
  • 對方如果在 LINE「隱私設定」關掉「允許外部應用程式存取」，就不會出現在名單裡。
  • 不能發到社群（OpenChat）。

一次可以發給很多人嗎？

選人畫面可以一次勾多位好友或群組。但每次都要本人操作，不能寫程式自動群發；需要自動推播就要用官方帳號的 Messaging API。

LIFF 以後還能用嗎？

LINE 在 2025 年公告，建議新做的 LIFF 改成 LINE MINI App，兩者會逐步整合。目前掛在 LINE Login channel 的 LIFF 仍然可以正常使用。
