自己做一個網頁，從個人 LINE 發出漂亮的卡片

不用官方帳號、不花錢。做完之後，你在 LINE 裡點一下、選好朋友，對方聊天室就會出現一張有顏色、有按鈕的卡片。

先看看我們要做到什麼

平常在 LINE 裡，我們只能打字、傳照片、傳貼圖。但你可能收過商家或官方帳號傳來的那種卡片：有標題、有底色、下面還有「立即報名」之類的按鈕。那種卡片，一般人的 LINE 並沒有地方可以做。

其實有個辦法可以自己發：寫一個小網頁，在 LINE 裡打開它，網頁上按一個按鈕，LINE 就會跳出「要傳給誰」的畫面。選好人、按送出，卡片就用你自己的名義送到對方的聊天室，就像你親手傳的一樣，也不用付任何費用。

這種卡片，LINE 叫它 Flex 卡片（Flex Message）；讓網頁跳出「要傳給誰」畫面的功能，叫 shareTargetPicker。名字先記著就好，後面用到時會再說明。

整件事由三樣東西組成

東西它是什麼放在哪裡
網頁一個 index.html 檔案，上面有「送出」按鈕，也寫好了卡片長什麼樣子GitHub Pages（免費幫你把網頁放上網路）
LINE 小程式入口一個專屬網址，在 LINE 裡點開它，網頁才能叫出 LINE 的「要傳給誰」畫面。LINE 把這種在 LINE 裡打開的網頁叫做 LIFFLINE Developers（LINE 給開發者用的後台）
卡片用一段文字描述卡片的標題、顏色、按鈕，這種格式叫 JSON寫在網頁裡

要準備的只有：一個 LINE 帳號、一個 GitHub 帳號、手機上的 LINE。

做的時候會遇到一個先後問題：在 LINE 後台登記入口時要填網頁網址，而網頁裡又要填 LINE 給的入口編號。所以步驟會是：先在 LINE 後台建好應用程式 → 做網頁、放上網路 → 回 LINE 後台登記入口、拿到編號 → 把編號填回網頁。下面照這個順序走。

1在 LINE 後台開一個「應用程式」

LINE 的所有開發功能都在 LINE Developers 後台。我們要先在裡面登記一個應用程式，LINE 稱它為 channel，之後的入口就掛在它底下。

  1. 打開 LINE Developers Console，用你的 LINE 帳號登入。
  2. 先建一個 Provider。它就像資料夾，名字隨意，填自己的名字就可以。
  3. 在 Provider 裡按 Create a new channel，類型選 LINE Login。
  4. 填名稱、說明，地區選 Taiwan，App types 勾 Web app，同意條款後建立。
⚠️ 類型要選 LINE Login清單裡還有一個 Messaging API，那是官方帳號機器人用的，它底下不能掛我們要的 LINE 小程式入口。選錯了，第 3 步會找不到 LIFF 分頁。

2做網頁，放上網路

網頁內容：直接複製範例

下面是一份已經能用的完整網頁。按右上角「複製」，存成一個叫 index.html 的檔案。你只需要改兩個地方，其他都不用動：

要改的地方改成什麼什麼時候改
LIFF_ID 那一行你自己的入口編號第 3 步拿到編號之後
message 裡的內容你想發的卡片先不改也可以，範例會發一張「讀書會提醒」
<!doctype html>
<html lang="zh-Hant">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>分享 Flex 卡片</title>
<style>
  body { margin: 0; padding: 24px 16px; font-family: system-ui, sans-serif; text-align: center; }
  button { width: 100%; max-width: 360px; padding: 14px; font-size: 1rem; font-weight: 700;
           color: #fff; background: #06c755; border: 0; border-radius: 12px; }
  button:disabled { opacity: .5; }
  #status { margin-top: 14px; color: #666; }
</style>
</head>
<body>
  <h1>分享 Flex 卡片</h1>
  <button id="share" disabled>選擇好友並送出</button>
  <p id="status">載入中…</p>

<!-- 1. 載入 LIFF SDK -->
<script src="https://static.line-scdn.net/liff/edge/2/sdk.js"></script>
<script>
  // 2. 換成你自己的 LIFF ID
  const LIFF_ID = "2011736396-qcyiLRJ3";

  // 3. 要送出的 Flex 訊息（可以到 Flex Message Simulator 設計後貼進來）
  const message = {
    type: "flex",
    altText: "讀書會提醒：週四晚上 8 點",   // 聊天列表與通知顯示的文字
    contents: {
      type: "bubble",
      header: {
        type: "box", layout: "vertical", backgroundColor: "#06c755", paddingAll: "16px",
        contents: [
          { type: "text", text: "讀書會提醒", color: "#ffffff", size: "xl", weight: "bold" },
          { type: "text", text: "週四 20:00｜線上", color: "#e8fff0", size: "sm" }
        ]
      },
      body: {
        type: "box", layout: "vertical", spacing: "md",
        contents: [
          { type: "text", text: "這次讀第 3 章，記得先看完再來喔！", wrap: true },
          { type: "text", text: "這張卡片是用 LIFF shareTargetPicker 從個人帳號送出的。", wrap: true, size: "xs", color: "#888888" }
        ]
      },
      footer: {
        type: "box", layout: "vertical",
        contents: [
          // 用 LIFF 分享的卡片，按鈕只能用 uri（開網址）
          { type: "button", style: "primary", color: "#06c755",
            action: { type: "uri", label: "看教學文章", uri: "https://iantpe.github.io/liff-share-test/guide.html" } }
        ]
      }
    }
  };

  const $ = (id) => document.getElementById(id);

  async function main() {
    // 4. 初始化 LIFF
    await liff.init({ liffId: LIFF_ID });
    if (!liff.isLoggedIn()) { liff.login(); return; }           // 在一般瀏覽器打開時先登入
    if (!liff.isApiAvailable("shareTargetPicker")) {
      $("status").textContent = "無法分享：請在 LINE 裡打開，並在 LIFF 設定開啟 Share target picker。";
      return;
    }
    $("share").disabled = false;
    $("status").textContent = "";

    // 5. 按下按鈕 → 跳出 LINE 的選好友畫面 → 送出
    $("share").onclick = async () => {
      try {
        const res = await liff.shareTargetPicker([message]);   // 一次最多 5 則
        $("status").textContent = res ? "已送出 ✅" : "已取消";
      } catch (e) {
        $("status").textContent = "失敗：" + e.message;           // 多半是 Flex JSON 格式有誤
      }
    };
  }
  main().catch((e) => { $("status").textContent = "LIFF 初始化失敗：" + e.message; });
</script>
</body>
</html>

這個網頁做的事情很單純：打開時先跟 LINE 打招呼（liff.init）；你按下按鈕時，請 LINE 跳出「要傳給誰」的畫面（liff.shareTargetPicker），並把卡片交給它。

卡片裡有一欄 altText，是卡片的「文字替身」。對方的聊天列表和手機通知看不到卡片，只會顯示這段文字，所以要寫一句看得懂的話。

放上網路：用 GitHub Pages

網頁要有一個網址，LINE 才找得到它。GitHub Pages 可以免費幫你把檔案變成網址。

  1. 在 GitHub 建一個新的 repository（可以想成一個專案資料夾），設成 Public，名字例如 liff-card。
  2. 按 Add file → Upload files，把 index.html 拖進去上傳。
  3. 進 Settings → Pages，Source 選 Deploy from a branch，Branch 選 main、/ (root)，按 Save。
  4. 等一兩分鐘，同一頁上方會出現你的網址，長得像 https://你的帳號.github.io/liff-card/。用瀏覽器打開，看得到頁面就成功了。

這時用電腦打開，頁面會說要登入或無法分享，這是正常的，因為還沒登記入口。

3回 LINE 後台登記入口，拿到編號

  1. 回到第 1 步建的 channel，切到 LIFF 分頁，按 Add。
  2. 照下表填：
    欄位填什麼說明
    LIFF app name隨意給自己看的名字
    SizeFull網頁在 LINE 裡以全螢幕打開
    Endpoint URL第 2 步的網址告訴 LINE 入口要連到哪個網頁
    Scopes勾 profile允許網頁知道是誰在用
  3. 建好後回到 LIFF 列表，把 Share target picker 切成 On。這個開關就是允許網頁叫出「要傳給誰」的畫面。大家最常忘的就是這一步。
  4. 複製列表上的 LIFF ID（長得像 1234567890-AbCdEfGh），貼到 index.html 的 LIFF_ID 那一行，再上傳一次覆蓋舊檔。

4在手機 LINE 裡試發一次

入口的網址是 https://liff.line.me/ 後面接你的 LIFF ID。要從 LINE 裡點開才行，最簡單的做法是把這個網址傳到任何一個聊天室，再點它。

  1. 點開後，看到頁面上的綠色按鈕「選擇好友並送出」。
  2. 按下去，LINE 會跳出「Share with」畫面，列出你的群組、好友和聊天室。
  3. 勾一個人，按 Share。頁面顯示「已送出 ✅」，對方就收到卡片了。

想先看看成品？可以在手機 LINE 裡點這個示範：liff.line.me/2011736396-qcyiLRJ3/demo.html。如果打不開，原因寫在下面「別人打不開我的入口」那一題。

5換成自己的卡片

卡片是一大段 JSON 文字，不用自己從頭打。LINE 有一個線上工具叫 Flex Message Simulator，可以用點選的方式設計，右邊即時看到樣子。

  1. 按左上角 Showcase，挑一個接近你想要的範本，例如餐廳、收據、行程。
  2. 在左邊點選元件，改文字、顏色、圖片。
  3. 改好後按 View as JSON，把整段複製起來。
  4. 貼到 index.html 裡 contents: 的後面，取代原本那張讀書會卡片，存檔、上傳。

在 Simulator 裡會看到的零件：

零件做什麼用要注意
box裝其他零件的框，可以直的排或橫的排—
text文字字比較多時要加 wrap: true，不然會被截斷
image圖片圖片網址要是 https；圖片可以一起放在 GitHub 上
button按鈕只能設定成「打開網址」，原因見下一節
separator分隔線—
💡 想讓卡片動起來卡片上的文字不能動，但圖片可以。放一張會動的 PNG（APNG），並在圖片零件加上 animated: true。

6會遇到的狀況

按鈕為什麼只能開網址？

卡片是用你個人帳號送出的，對方按按鈕時，LINE 沒有一個「機器人」可以接收。所以凡是要傳資料回去給機器人的按鈕，都要改用官方帳號發卡片才行。能直接打開網頁的按鈕則沒有問題。

按鈕按下去會用這個方法能不能做
打開一個網址（加入 Zoom、填報名表、看活動頁）✅ 可以，網址最長 1,000 字
回傳資料給機器人❌ 要官方帳號
替對方送出一句話❌ 要官方帳號
複製一段文字❌ 要官方帳號
選日期時間❌ 要官方帳號

其他常見狀況

你看到的為什麼怎麼辦
頁面說「無法分享」Share target picker 沒開，或不是從 LINE 裡點開檢查第 3 步的開關；確認是從 liff.line.me/… 網址點開
別人打不開我的入口剛建好的 channel 處於「開發中」（Developing），只有你自己和你加的測試人員能打開在 channel 頁面上方改成 Published，或在 Roles 分頁把對方加成測試人員。收卡片的人不受影響，卡片誰都看得到
按送出後跳出錯誤卡片的 JSON 有地方寫錯，例如少一個逗號把 JSON 貼回 Flex Message Simulator，它會指出錯在哪
改了網頁，LINE 裡還是舊的LINE 會暫存網頁，GitHub Pages 大約 10 分鐘才更新在網址後面加 ?v=2、?v=3，每次換個數字
找不到某位好友對方在 LINE 隱私設定裡關了「允許外部應用程式存取」請對方打開，或改用一般方式傳
選人畫面裡沒有自己這個畫面本來就不能傳給自己，也沒有 Keep測試時傳給家人，或開一個只有你和一位朋友的小群組
找不到社群（OpenChat）這個功能不支援社群—

可以一次發給很多人嗎？

可以在選人畫面一次勾好幾個人或群組。但每一次都要你自己打開、勾選、按送出，沒辦法讓程式在背後自動一直發。需要自動發送，就要改用官方帳號，而官方帳號主動發訊息是要算錢的。

這個方法以後還能用嗎？

LINE 在 2025 年公告，建議新做的 LIFF 改成「LINE MINI App」，兩者會慢慢整合。目前用 LINE Login channel 建的 LIFF 仍然正常運作。

接下來可以這樣做

建議第一次先完全不改卡片，只換掉 LIFF_ID，把範例的讀書會卡片發給一位家人或朋友。確定整條路走得通，再去 Simulator 換成自己的卡片。這樣萬一出問題，比較容易分辨是設定沒做好，還是卡片寫錯了。這是建議的練習順序，不是必要步驟。
